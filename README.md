# AI Quiz Generator

An AI-powered Quiz Generator built with Python and Flask that automatically generates topic-based MCQs using Google Gemini API.

## Tech Stack
- Python
- Flask
- Google Gemini API
- Prompt Engineering
- HTML & CSS

## Features
- Generate MCQs on any topic instantly
- AI-powered question generation using Google Gemini API
- Clean and interactive UI
- Restart quiz functionality

## How to Run

1. Clone the repository
   git clone https://github.com/arbaazmalik/AI-Quiz-Generator.git

2. Install dependencies
   pip install flask google-generativeai python-dotenv

3. Add your API key
   Create a .env file and add:
   GEMINI_API_KEY=your_api_key_here

4. Run the app
   python app.py

5. Open browser
   http://localhost:5000
